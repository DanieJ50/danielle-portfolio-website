THE NEW ANIMATION CONCEPT

Camera shutter + recipe reel + moving BerryBelle bookmark.

Each recipe poster begins as a narrow slit, opens like a camera shutter, settles into a slightly tilted print, and reveals its recipe ticket. BerryBelle travels down the edge of the page as a live bookmark while the reel counter changes with your scroll.

NO HOTLINKED FOOD IMAGES

Every recipe poster is a local SVG file inside this project, so GitHub Pages does not depend on an outside image host.
